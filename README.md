### What I'm working on

**[supply-chain-optimizer](https://github.com/ApagPlayz/supply-chain-optimizer)** — electronics
sourcing on real market data.
A two-stage stochastic program minimizing mean-CVaR via Rockafellar-Uryasev linearization, an
intermittent-demand forecasting benchmark across 2,646 spare-parts series, and a model CI suite
that asserts published numbers match committed artifacts byte-for-byte.
`Python` · `OR-Tools CP-SAT` · `FastAPI` · `React` — [live demo](https://supply-chain-ui-bhwz.onrender.com)

**[loop-dashboard](https://github.com/ApagPlayz/loop-dashboard)** — a control plane for autonomous
coding agents.
Agents propose, build, review and demo changes on GitHub; a human approves each step. A LangGraph
agent halts at a checkpointed interrupt before any write. Ships through keyless GitHub Actions
OIDC to ECR and ECS Fargate.
`TypeScript` · `Next.js` · `LangGraph` · `AWS Bedrock` — [live demo](https://d1ougmzejkasx3.cloudfront.net)

**[portalpair](https://github.com/ApagPlayz/portalpair)** — semantic transfer-portal search
(Hackalytics 2026).
Player embeddings in a cosine HNSW vector store, an Express API, and per-statistic forecasting
in PyTorch. Built with a team of four.
`Python` · `Node.js` · `ChromaDB` · `PyTorch`

**[claude-launcher](https://github.com/ApagPlayz/claude-launcher)** — a tiling, multi-session
window manager for Claude Code on macOS.
