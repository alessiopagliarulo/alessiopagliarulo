## About

I'm an Industrial &amp; Systems Engineering student at Georgia Tech who builds systems that have to
make a decision under uncertainty — where to source parts, what intermittent demand does next,
whether an agent's proposed change is safe to merge.

The part I care most about is the evidence behind the answer: pinned data vintages, honest
validation, controls designed to fail, and CI that breaks the moment a published number stops
matching the artifact it came from.

## 🛠️ Selected work

**[loop-dashboard](https://github.com/alessiopagliarulo/loop-dashboard)** — a control plane for
autonomous coding agents.
Agents propose, build, review and demo changes on GitHub; a human approves each step. A LangGraph
agent halts at a checkpointed interrupt before any write. Ships through keyless GitHub Actions
OIDC to ECR and ECS Fargate, on AWS Lambda, Bedrock and S3.
`TypeScript` · `Next.js` · `LangGraph` · `AWS Bedrock` — [live demo](https://d1ougmzejkasx3.cloudfront.net)

**[iexbook](https://github.com/alessiopagliarulo/iexbook)** — a C++20 order book engine over raw
IEX DEEP captures.
A fine-tuned PatchTST transformer (PyTorch → ONNX) runs inside the replay loop, validated with
purged and embargoed cross-validation, a linear control on the identical window, and a label
permutation. It publishes an honest negative result instead of a headline.
`Python` · `C++20` · `PyTorch` · `ONNX`

**[claude-launcher](https://github.com/alessiopagliarulo/claude-launcher)** — a tiled, multi-session
window manager for Claude Code on macOS.
Opens each project in its own Terminal window and auto-tiles them across your displays.
`bash` · `AppleScript` · `JXA`
